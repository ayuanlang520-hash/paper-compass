# PaperCompass

**Find the focus. Read the evidence. Build your judgment.**

PaperCompass 是一个对话式论文阅读导师 Skill，采用 Codex 技能格式。它帮助使用者先判断论文重点，再围绕原文和图表逐步理解研究，并保留自己的判断。

技能指令与说明主要使用中文；实际陪读语言跟随使用者。它适用于不同研究领域，不预设使用者的研究方向。

## 它怎样陪你读论文

1. **先找重点。** 梳理研究问题、研究设计或论证路径、主要发现与结论边界，说明哪些部分值得优先读、为什么重要。
2. **把重点讲具体。** 围绕一个原文实例，解释术语、实际操作、分析步骤和判断依据，讲清后连接回研究主线。
3. **共同推理。** 一次提出一个问题；卡住时先给提示，再视需要示范。可以跳过问题，也可以直接要求解释。
4. **保留证据边界。** 区分作者报告、助手分析、使用者观点和未知；结论提供原文定位。
5. **每阶段暂停。** 小结当前理解、使用者的想法、待查问题和阅读停点，等待确认后继续。
6. **逐步适配个人。** 明确的长期偏好可以保存在本地；从表现中推测的习惯，先确认再记录。

对横置、倒置的图表，技能会要求宿主工具先调整阅读方向；表格另提供所需语言的翻译版本，并保留行列、数字、单位、符号与脚注。能否实际处理取决于宿主提供的 PDF、图像或 OCR 工具。

## 安装

将本仓库下载或克隆到本机，把包含 `SKILL.md` 的文件夹命名为 `paper-compass`，放到 Codex 的技能目录。

- 默认位置：`~/.codex/skills/paper-compass/`
- Windows 默认位置：`%USERPROFILE%\.codex\skills\paper-compass\`
- 如果设置了 `CODEX_HOME`，使用其 `skills/paper-compass/` 子目录。

确认当前可用技能清单包含 `paper-compass` 后，再调用它。其他技能宿主能否直接使用这一包，尚未验证。

## 使用示例

提供 PDF、可访问的论文链接、文件路径或原文片段，然后发送：

```text
请用 $paper-compass 陪我读这篇论文。
先判断重点并说明原因，再分阶段细读，每阶段结束后暂停。
```

也可以指定一个问题：

```text
请用 $paper-compass 帮我弄清这篇论文如何把学生回答转成评分。
先解释必要概念，再沿着一个原文例子逐步分析。
```

续读时提供上一阶段的小结或准确停点。技能不会仅凭“之前读过”就把论文记作已完成；没有可靠上下文时，会询问恢复阅读必需的信息。

讨论这个 Skill 的修改、测试或交付时，试读只服务于约定的验证问题；“继续”应承接当前技能阶段。

## 个性化与本地文件

公开的 `references/reading-preferences.md` 只包含通用默认值。个人阅读偏好保存在可选的 `references/reading-preferences.local.md`，这个文件不会随发布包提供，并已加入 `.gitignore`。

- 优先顺序：当前明确指令 → 本地个人偏好 → 公开默认值。
- 明确表达的长期偏好可以直接保存；助手推测出的习惯先确认。
- 临时要求仅用于当次阅读，只读要求也适用于偏好文件。
- 不把私人档案写回公开模板；提交更新前检查实际暂存文件。

Git 忽略规则只影响 Git 的默认跟踪，不提供加密，也不会自动控制其他同步或上传工具。

如使用者提供文献整理表并授权，技能可按原有结构整理阅读记录并核对保存结果。它不自动创建工作簿、知识库或同步服务。

## 依赖与验证范围

本仓库包含技能指令、默认偏好和调用配置，不包含独立应用、论文 PDF、模型、OCR 引擎或 Excel 控制器。技能本身不要求 API 密钥；阅读、渲染和写入能力由宿主提供。缺少工具或材料时，技能应说明限制，不能声称已处理未见内容。

公开包的结构、元数据、引用文件和个人档案忽略规则会在发布准备阶段检查。原始个性化流程已做过短段落试读；公开模板尚未完成跨用户、跨学科的行为验证。真实倒置图表处理、Excel 写回和跨聊天续读仍需要在各自宿主环境中验证。
