# 默认阅读偏好

这是公开的起始模板，不是任何使用者的个人档案。以下内容是 PaperCompass 的默认做法，不代表用户已经逐项确认；当前指令和已确认的本地个人偏好可以调整这些默认值。

## 默认做法

- 讲解语言跟随用户，关键术语保留原文，难句按需翻译。
- 先梳理论文问题、研究设计或论证路径、主要发现和结论边界，识别值得优先阅读的部分。
- 一次深入一个核心问题，围绕原文实例逐步解释，完成当前阶段后暂停。
- 用户卡住时先给线索，再视需要示范；允许跳过或直接要求解释。
- 当前问题讨论完后，再简短提出有证据支持的跨文献联系。
- 阶段小结留在聊天中；只有用户提供记录表并授权时才更新表格。

## 首次使用与后续调整

- 不预设研究方向、阅读水平或学习卡点。用户尚未提供且影响当次阅读时，只询问必要的信息。
- 个人长期偏好写入同目录的 `reading-preferences.local.md`。该文件不存在时，不需要为了开始阅读而创建空档案。
- 用户明确表达长期偏好时直接记录；助手观察到的潜在习惯先确认，临时要求不自动固化。
- 本地档案只保留当前有效的偏好、可变研究背景、确认日期及简短依据；论文事实、具体想法与阅读停点保留在聊天或用户指定的记录载体中。
- 不把个人调整写回本公开模板。本地档案已加入 Git 忽略规则，公开分享前仍应核对实际待提交的文件。
